# Employee Portal

A secure Employee Portal for managing users, roles, permissions, audit logs, and Zoho People integration.

## Features

- JWT Authentication
- Role-Based Access Control (RBAC)
- User Management
- Role Management
- Permission Management
- Audit Logs
- Zoho OAuth Integration
- Zoho People Integration
- Protected API Routes
- Secure Token Storage
- Responsive Dashboard

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

### Integrations
- Zoho People API
- Zoho OAuth 2.0
